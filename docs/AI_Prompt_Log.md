# HomeServe – AI Prompt Log

## 1. Project Information

**Project Name:** HomeServe – Home Services Booking SaaS Platform  
**Frontend:** React.js + Vite  
**Backend:** Python FastAPI  
**Database:** MySQL  
**ORM:** SQLAlchemy  
**Deployment:** Vercel (Frontend) and Render (Backend)  
**Version Control:** GitHub  

## 2. Purpose of AI Usage

AI tools were used during the development of HomeServe to support coding, debugging, project planning, documentation, API development, and deployment guidance.

AI-generated suggestions were reviewed and modified according to the actual project requirements.
