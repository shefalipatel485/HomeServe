# 8. Capstone Evaluation Mapping (100 Marks)

Use this mapping to organize the project report, screenshots, test evidence and final demonstration. The marks below reproduce the evaluation areas in the capstone rubric; they are maximum marks, not self-assigned scores.

| Evaluation area | Marks | HomeServe evidence to submit |
|---|---:|---|
| Requirement Analysis & Planning | 5 | SRS, user stories, workflows, scope and roadmap (Phase 1 documents). |
| UI/UX & Frontend | 15 | Screenshots of responsive React screens, role dashboards, navigation, forms and validation. |
| Database Design | 10 | Physical ER diagram generated from actual tables, primary/foreign keys, relationships and schema evidence. |
| Backend & REST APIs | 15 | FastAPI endpoints, Swagger `/docs`, CRUD demonstrations, validation and API test evidence. |
| Frontend-Backend Integration | 10 | End-to-end demonstrations showing React screens reading/writing backend data. |
| Testing & Quality Assurance | 10 | Test cases, full Pytest run output, bug/fix evidence and regression results. |
| Security Implementation | 10 | JWT authentication, role authorization, ownership checks, password hashing and secret-handling evidence. |
| GitHub & Version Control | 5 | Repository URL, commit history, README, `.gitignore` and `.env.example`. |
| Deployment | 10 | Verified frontend/backend URLs, production database connectivity, HTTPS and live workflow test. |
| Documentation & Presentation | 10 | Final report, architecture/use-case/ER/workflow diagrams, screenshots and presentation. |
